# 稳进 · 12周减脂保肌追踪器

这是一个零依赖、离线运行的单文件网页，用于执行和追踪已经确定的12周减脂保肌方案。

## 使用方法

1. 双击打开 `index.html`。
2. 在“设置”中填写计划开始日期、健身房称得的起始体重和肚脐水平腰围。
3. 每天记录热量、蛋白质、步数和饮水；每周至少称重3次、量腰围1次。
4. 在训练页点击动作下方的“动作教学”，先查看离线示意图、起始设置、三步动作、呼吸和常见错误，再记录每组重量、次数和RIR。达到次数上限且仍保留1–2次余力时，应用会提示下次加重。
5. 连续记录两周后，到“进度”页查看自动调整建议。
6. 每周从“设置”导出一次JSON备份。

所有数据只保存在当前浏览器的 `localStorage` 中，不会上传。清理浏览器数据、更换浏览器或更换电脑前，请先导出备份。

## 已实现

- 周一/周二/周四/周六四练和第6、12周减量逻辑
- 训练重量、次数、RIR及完成状态记录
- 全部训练动作的离线SVG图解、目标肌群、动作步骤、呼吸、常见错误和疼痛替代方案
- 2150 kcal与三大营养素、步数、饮水、蔬果、跑步记录
- 外卖热量增加15%的快捷估算与每周炸鸡餐标记
- 体重、腰围、卧推表现趋势图
- 基于两个7天周期的减重速度、腰围、力量与执行率调整建议
- 明暗主题、手机适配、数据导入导出与本地持久化

## 健康边界

本工具面向无运动禁忌的健康成人，不替代医生或注册营养师。出现胸痛、眩晕、异常气短或持续关节锐痛时停止训练并就医；有肾病、肝病、进食障碍或其他医疗限制时，不直接使用该方案。
