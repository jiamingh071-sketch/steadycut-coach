# SteadyCut 2.1

一套为 12 周减脂保肌设计的离线优先个人训练软件。它把训练前评估、组间决策、休息计时、动作教学、饮食和趋势调整装进同一条训练流程。

2.1 将界面统一为深石墨、近白文字与琥珀强调色的高级极简训练工具：手机端更适合单手记录，电脑端提供窄侧栏与更宽的进度分析区；训练单会优先呈现重量、次数、RIR 与组间休息。

## 已实现

- React + TypeScript + Vite 的可安装 PWA，核心功能安装后离线可用。
- Capacitor Android 独立 APK 工程，网页与 APK 共用经过测试的领域逻辑。
- 30 / 45 / 60 分钟训练版本；第 1 周 RIR 3；第 6、12 周自动减量。
- 每组记录重量、次数、RIR、稳定性与不适，并立即写入 IndexedDB。
- 锁屏、刷新、关闭后恢复当前动作、组数与休息结束时间；Android 在休息开始时预约系统通知。
- 锐痛、麻木、关节不稳、胸痛、眩晕或异常气短触发不可被普通建议覆盖的安全暂停。
- 本地规则教练、器械受限替换建议、本地周复盘与 ChatGPT Plus 手动桥接；调整代码经过会话、动作白名单和数值边界校验后才可确认应用，并可在下一组前撤销。
- 29 套原创离线动作教学：三阶段分镜、两种错误对照、轨迹、器械设置、呼吸、节奏、停止信号和替代动作。
- 2150 kcal 起始方案、外卖规则、炸鸡餐预算、体重/腰围/执行趋势。
- AES-GCM + PBKDF2 加密备份，支持网页和 APK 之间手动迁移；恢复前需二次确认，并保留 v1 原始数据导出入口。

## 本地运行

```bash
npm ci
npm run dev
```

生产验证：

```bash
npm run typecheck
npm test
npm run build
```

Android 同步：

```bash
npm run android:sync
```

正式 APK 由 GitHub Actions 使用仓库 Secrets 中的持久签名密钥生成；密钥不会进入仓库。

## 数据与隐私

没有账号、后端或云同步。网页使用 IndexedDB，APK 使用应用内 WebView 存储。不同设备不会自动同步；请从“更多 → 加密备份”导出 `.steadycut` 文件。清除浏览器数据、卸载 APK 或忘记备份密码可能永久丢失数据。

## 一般指导声明

SteadyCut 提供一般健身与营养指导，不进行医疗诊断。动作教学尚未经过持证专业人员逐条复核。出现锐痛、麻木、关节不稳、胸痛、眩晕或异常气短应停止训练；症状严重、持续或反复时及时就医。
